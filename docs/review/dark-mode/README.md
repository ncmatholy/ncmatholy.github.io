# Light and dark themes

Use the moon/sun button beside the main navigation (next to Menu on phones) to switch themes. Your choice stays selected across pages and future visits. Before you make a choice, the site follows your device's theme.

The dark theme uses warm charcoal, ivory text, pale green links and logos, and the existing coral accents. Screenshots are from the built site at 1440 px desktop and 390 px mobile widths.
